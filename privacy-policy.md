# Prompt Guard – Gizlilik Politikası

**Son güncelleme:** 15 Eylül 2026

Prompt Guard, kullanıcıların ChatGPT'ye göndermeden önce promptlarını belirlenen yasaklı kelimeler açısından kontrol etmelerini sağlayan bir Chrome uzantısıdır.

## 1. Toplanan Veriler

Prompt Guard, kullanıcıların kişisel verilerini toplamaz, saklamaz veya satmaz.

Uzantı:

- Kullanıcıların adını, e-posta adresini veya iletişim bilgilerini toplamaz.
- Kullanıcıların ChatGPT hesap bilgilerine erişmez.
- Kullanıcıların ChatGPT promptlarını herhangi bir sunucuya göndermez.
- Kullanıcıların prompt geçmişini toplamaz veya saklamaz.
- Kullanım analitiği veya telemetri verisi toplamaz.

## 2. Prompt İçeriği

Prompt Guard, ChatGPT'deki prompt giriş alanını yalnızca yasaklı kelime kontrolü yapmak amacıyla yerel olarak inceler.

Prompt içeriği:

- Prompt Guard tarafından harici bir sunucuya gönderilmez.
- Prompt Guard tarafından saklanmaz.
- Üçüncü taraflarla paylaşılmaz.

Bir prompt içerisinde yapılandırılmış yasaklı kelimelerden biri bulunursa, uzantı promptun gönderilmesini engeller.

## 3. Yasaklı Kelime Listesi

Prompt Guard, yasaklı kelime listesini merkezi bir kaynaktan alabilir.

Bu liste yalnızca uzantının kontrol mekanizması tarafından kullanılan yapılandırma verisidir ve kullanıcı verisi değildir.

Merkezi listedeki veriler, uzantının çalışması için tarayıcıya indirilebilir ve yerel olarak kullanılabilir.

## 4. Yerel Depolama

Prompt Guard, Chrome'un `storage` API'sini kullanarak uzantının yapılandırma bilgilerini kullanıcının cihazında yerel olarak saklayabilir.

Bu bilgiler, örneğin kullanıcının kendi belirlediği yasaklı kelime listesini içerebilir.

Bu bilgiler Prompt Guard tarafından kendi sunucularımıza gönderilmez.

## 5. Üçüncü Taraf Hizmetler

Prompt Guard, kullanıcı verilerini üçüncü taraf hizmetlere göndermez.

Uzantı, merkezi yasaklı kelime listesini almak amacıyla GitHub gibi harici bir kaynağa HTTP isteği gönderebilir.

Bu istekler kullanıcı promptlarını veya kişisel kullanıcı bilgilerini içermez.

## 6. Veri Paylaşımı ve Satışı

Prompt Guard:

- Kullanıcı verilerini üçüncü taraflarla satmaz.
- Kullanıcı verilerini reklam amacıyla paylaşmaz.
- Kullanıcı verilerini profil oluşturma amacıyla kullanmaz.

## 7. Veri Güvenliği

Prompt Guard'ın prompt kontrol işlemi kullanıcının tarayıcısı içerisinde gerçekleştirilir. Kullanıcı promptlarının Prompt Guard tarafından bir sunucuya gönderilmemesi, prompt içeriğinin uzantının kendi sunucularında depolanmasını önler.

## 8. Çocukların Gizliliği

Prompt Guard, bilerek çocuklardan kişisel veri toplamaz.

## 9. Gizlilik Politikasındaki Değişiklikler

Bu gizlilik politikası, Prompt Guard'ın işlevlerinde veya veri işleme yöntemlerinde değişiklik olması durumunda güncellenebilir.

Güncellenen politika aynı URL üzerinden yayınlanacaktır.
